# C Programming Practice

Small practice programs in C and C++ that I wrote while learning the fundamentals of the language. Each file is a short, self-contained program on one topic.

## Topics covered
- **Basics:** operators (relational, logical, bitwise, conditional), implicit conversion, escape sequences, formatted input and output with `scanf()`
- **Control flow:** `if` ladders, `switch`, `for`, `while` and nested loops, jump statements
- **Functions and recursion**
- **Arrays:** 1D and 2D arrays
- **Strings:** string handling programs
- **Pointers:** pointer basics and pointer programs
- **Memory:** dynamic memory allocation with `malloc`, storage classes
- **Structures and unions**
- **Searching and sorting:** linear search, binary search, bubble sort
- **Small programs:** palindrome check and others

## Running a program
```bash
gcc "Palindrome.c" -o palindrome
./palindrome
```
For `.cpp` files use `g++` instead of `gcc`.
